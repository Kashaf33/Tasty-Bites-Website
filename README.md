Tasty Bites Restaurant Website
A restaurant website developed using HTML, CSS, and JavaScript. The project displays restaurant information, menu items, and interactive features for users.

Technologies Used
HTML5
CSS3
JavaScript
🚀 How to Run the Project
You can view the live project directly here:Live Demo

Alternatively, to run it locally:

Clone or download this repository.
Open the project folder.
Double-click the index.html file.
The website will open in your browser.
Note: For the best experience, use Google Chrome or Mozilla Firefox.
